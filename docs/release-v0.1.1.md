# v0.1.1

修复 v0.1 默认配置无法采集、单独 EXE 缺少场景模板的问题。

直接下载 timer-app.exe，放在可写目录后运行；场景模板、掩码和识别字典已内置，无需另找模板。也可下载完整 ZIP，解压运行「启动计时器.bat」。

先启动本机 MuMu 和游戏。程序会从运行中的 MuMu 进程自动定位安装目录，并使用本机自带的截图 SDK；不分发模拟器 DLL。默认连接实例 0，多开用户可修改 config.json 中 capture.mumu.instance。存在多个安装目录时，请设置 capture.mumu.installDir。

首次使用请在设置填写自己的游戏账号名，或手动指定己方所在边。个人账号名不内置。程序在 EXE 所在目录保存配置；完整包的 bin 程序使用包根目录。

采集失败时，点击浮窗「诊断」查看具体原因。录制仍只保存确认处于对局中的画面，并有容量限制。延迟报告继续排除无有效帧和未完成绘制的样本。
