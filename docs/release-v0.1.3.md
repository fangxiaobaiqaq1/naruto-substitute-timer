# v0.1.3

本版改进对局顶部姓名识别：Windows x64 EXE 内置 PP-OCRv4 中文模型和 CPU ONNX Runtime，普通忍者名字走本机 OCR 与完整资料库核对。完整忍者目录（2490条记录，含变体和内部项）及替身表均已编译内置，不需要外部图片库、Python 或系统中文 OCR 语言包。本次没有新增单个人物的普通姓名图片模板。

「诊断」增加程序版本、OCR 后端、内置库数量和文字识别状态/错误，可直接确认是否运行了新版及模型是否可用。新增库内中点姓名支持；保留严格匹配、多个视图与不同采集时间的重复确认，缺字不会自动猜版本。采豆继续异步运行，不等待文字模型。

验证范围：

- 三张对局截图经正式确认路径，右侧依次确认基础名「宇智波带土」「神秘面具男」「神秘面具男」；遮挡姓名后撤销旧结果。第一张未完整读出版本括号，仅确认基础名。
- 四张训练营原生图回归：左侧均4豆，右侧依次2、4、6、2豆；右侧槽数依次4、4、6、6。原生图不含 MuMu 顶栏，不按桌面复合截图裁切。
- 工作进程的关闭与重启、低置信字符拒绝确认有回归覆盖。截图验证不能代表整场事件准确率或端到端延迟；低清复合图中的部分左侧姓名仍不能可靠确认。

下载 `timer-app.exe` 放在可写目录运行，或解压完整 ZIP。先退出旧版，再启动新版并在「诊断」核对 `v0.1.3`。默认 MuMu 实例0；在设置中填写自己的账号名或手动选边。

运行环境为 Windows 10/11 x64。首次启用模型会在当前用户缓存目录释放并校验内置 ONNX DLL，同版本复用。系统还需 Microsoft Visual C++ v14 x64 运行库；若诊断显示运行库加载失败，请从 [Microsoft 官方下载页](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) 安装最新 x64 版本。该要求来自 [ONNX Runtime 官方文档](https://onnxruntime.ai/docs/install/)。模型本身不联网识别或下载。

采集日志、有效对局原帧录制和分阶段延迟报告继续可在「诊断」开启。只有有效帧完成对应阶段才计入延迟统计，无帧重试与函数耗时不会冒充完整端到端延迟。原创代码采用 MIT；模型、运行库及游戏资料保留各自许可与归属，见 [第三方声明](../THIRD_PARTY_NOTICES.md) 和 [模型来源记录](../internal/ocr/neuraldata/provenance.json)。
