# v0.1

首个 Windows x64 发布版，项目原创代码采用 MIT 协议。

下载 naruto-substitute-timer-v0.1-windows-amd64.zip，完整解压后运行「启动计时器.bat」或 bin/timer-app.exe。保留 assets、配置与程序的相对目录结构。单独的 timer-app.exe 用于替换已有完整安装中的同名文件。

需要已安装的 MuMu 模拟器和游戏；采集 DLL 使用本机安装版本。请在设置填写自己的账号名或手动指定己方所在边。系统 OCR 可在设置中关闭。

包含替身豆识别、对手冷却浮窗、训练场/决斗场布局、特殊豆型、前端诊断与原帧/HUD录制、P50/P95/P99报告，以及 timer-lab 离线工具。

仅在确认的对局画面保存图片；总图片上限 1 GiB，其中预留 256 MiB 给每秒最多两张的原像素 HUD 截图。缺帧、未知及未实际绘制的链路不冒充端到端延迟。

初始版本仍有识别局限：部分忍者的决斗场识别需要更多实图验证，未知时不推断替身。延迟截至本程序缓冲提交，不包含游戏内部或显示器物理延迟。

源码不含个人录制及账号模板，相关实图测试需要自行提供样本。使用 Go 1.26.1、CGO/C 编译器和 build.bat 构建，可接入 Fyne 2.6.3 的实际绘制回调。
