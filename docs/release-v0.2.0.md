# v0.2.0

## 新增

- 浮窗标题和“关于与更新”显示版本号，提供 GitHub 最新正式版检查。
- 在线下载显示进度、支持取消；校验 SHA256 和程序版本后，由用户选择重启安装。更新保留设置并留下一个旧EXE备份。
- 更新日志可按版本选择，显示真实GitHub发布日期；网络失败时仍可阅读缓存。
- 设置新增“模拟器”选项卡。默认自动找正在运行游戏的MuMu实例，也可按安装目录和实例编号手动指定；多个游戏实例时提示选择。
- 提供当前用户 Setup、便携EXE和完整ZIP。安装版配置移到用户AppData，升级与卸载保留个人设置和日志。

## 改进

- 切换实例时清除计时基线，拒绝旧实例迟到帧。
- 三个设置选项卡和卡片布局，常用入口保留在浮窗。
- 精简README及重复进度文档，保留使用、诊断、开发和历史发布说明。
- 玩家提供的水门/须佐卡卡西训练场截图，游戏区域验证为训练场、左4/右4；包含桌面和窗口边框的整图不能作为原始采集帧。

v0.1.x 用户需要先手动安装/下载一次本版，之后可使用应用内更新。自动检测需要受支持的 MuMu 多开管理与截图接口；无法唯一确定游戏实例时不会猜选。更新依赖能访问 GitHub，网络错误会保留当前版本。
