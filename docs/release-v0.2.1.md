# v0.2.1

## 新增

- 正式版会在启动约 10 秒后自动检查 GitHub 最新正式版，之后最多每 6 小时检查一次；发现新版时计时浮窗显示入口。自动检查只提醒，下载、安装和重启仍需用户主动确认。
- 「设置 → 常规 → 外观与更新」新增计时浮窗不透明度（40%–100%）和字号（80%–160%）。拖动即时预览，松开后保存；设置窗口和错误提示保持不透明。

## 更新安全与兼容

- 自动检查与手动检查复用同一个受限 GitHub 请求，合并并发请求、缓存成功结果，关闭应用时取消后台工作。网络失败或限流保持安静，不影响计时。
- 下载仍只接受本仓库正式 Release 的 `timer-app.exe`，并验证 GitHub SHA256、文件大小和程序版本；不会自动覆盖现有程序。
- 旧版 `config.json` 自动继承新设置的默认值：启用自动检查、100% 不透明度、100% 字号。

## 测试

- 覆盖自动检查的新版通知去重、开发构建/同版本静默、网络错误、请求合并和关闭取消。
- 覆盖配置兼容、透明度/字号边界、即时预览、保存及单双读秒字号切换。

**v0.2.0 或更早版本需先手动检查/下载本版一次；升级后才会拥有自动提醒功能。**
