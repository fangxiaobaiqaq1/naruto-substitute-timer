# v0.2.2

## MuMu 多开与 SDK 诊断

- 「设置 → 模拟器」现在区分安装目录与实例编号：同一台电脑多套 MuMu 安装中的实例 `0` 不会再混为同一个目标。
- 扫描结果显示 MuMu 实例的运行状态，并尽量关联 Windows PID；无法可靠确认的进程编号不会默认写成实例 `0`。
- 选择目录或实例后改为明确草稿状态；只有点击“使用选中的进程”或“保存并应用手动实例”才会保存 `config.json` 并请求采集器切换。页面会显示已保存、已请求应用、已应用和最近连接错误。
- 新增“测试当前选择（不保存）”和“验证 MuMu SDK”：在独立进程中验证 SDK 连接与一帧截图，避免厂商 SDK 卡住界面。
- SDK DLL 搜索改为稳定优先顺序，并在诊断中记录候选 DLL、时间、大小和 SHA-256。

## 支持诊断包与反馈

- 新增“导出支持诊断包（ZIP）”。默认不包含原帧 PNG，包含实际配置、MuMu 安装目录、实例号、PID、SDK DLL、连接阶段、系统信息和已有诊断日志。
- 「关于与更新」、诊断窗口、README 和使用说明加入 BUG 反馈 QQ 群：**1109044204**。

## 验证

- 覆盖支持 ZIP 的允许列表：不会自动打包任意文件或原帧 PNG。
- 运行普通测试与 Windows x64 目标测试。
