# v0.2.4

## 训练场特殊替身豆显示

- 修复十尾带土等特殊忍者的顶部名字被短暂遮挡时，浮窗把整侧替身豆显示为 `?` 的问题。
- 训练场中带土紫豆 4/4、对侧六槽 2/6 的当前画面会继续显示为 `左4/4 / 右2/6`，不再退化为 `左? / 右2/6`。
- 特殊名字短暂丢失时，不再读取旧一帧的豆数：每颗豆仍必须由**当前帧**像素确认。

## 防误判边界

- 名字缺失窗口仅保留已验证的槽位结构和内部皮肤判色提示，不作为当前角色名称或历史豆数。
- 暗色豆可由当前像素继续显示；十尾带土仅在当前格具备强紫色豆体、且未命中特效扩散保护时显示亮豆。
- 大范围紫色特效、白光、金色/红色特效和其他没有当前帧充分证据的格子继续显示未知，不能据此触发替身倒计时。

## 验证

- 覆盖特殊名字短暂丢失时的暗豆、紫色亮豆和大范围紫色特效回归。
- 已运行：`go test ./internal/... ./cmd/...`。
