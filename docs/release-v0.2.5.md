# v0.2.5 · 替身豆识别与实战漏报修复

## 修复内容

- 修复侠隐佐助豆行位置识别，支持同场出现的紫色、红色配色。左右分别依据当前画面判断，不再把对方红豆全部显示为问号。
- 补充侠隐佐助、十尾带土完整版本姓名的视觉适配，改善名字识别断续导致的未知读数。
- 改善普通蓝豆受头像光效染色、紫豆/红橙豆扫光、空豆边框发光时的读数稳定性；伤害数字经过豆体下方不再一概视为豆体被遮挡。
- 修复因连续未知读数丢失判定基线而漏报替身的问题。开局校准改为左右独立完成，一侧暂时读不清不再阻塞另一侧。
- 保留真实遮挡保护：不复用旧豆数、不把大范围光效或空心边框当作亮豆，不根据遮挡前后差值猜测替身。

## 验证与已知限制

- 用户提供的 1061 帧实战录像回放中，至少一侧未知由 853 帧降至 35 帧；检出三次已核对的替身，包括约 23.67 秒的原漏报。
- 新反馈的侠隐佐助红紫同场截图在原尺寸及多种缩放下均读为左 2、右 3；补充遮字、掉豆、重复帧、配色互换及提示过期回归。
- 完整代码测试、静态检查和 Windows 构建通过。上述录像经过压缩，不代表所有忍者、分辨率和整场实战的准确率；**强特效或证据不足时仍可能短暂显示未知**。

## 下载与更新

- `timer-app.exe`：便携版，也用于程序内在线更新。
- `naruto-timer-v0.2.5-setup-x64.exe`：当前用户安装包，提供快捷方式和卸载入口。
- `naruto-timer-v0.2.5-windows-x64.zip`：完整包，包含计时器、诊断/校准工具及第三方许可。

已有正式版用户可在「关于与更新」中检查更新，下载校验完成后选择「重启并更新」。`v0.2.5-dev.*` 开发版不支持在线覆盖，请手动下载正式版 EXE，退出旧窗口后运行。个人设置保留；软件未签名，Windows 仍可能显示下载信誉提示。
