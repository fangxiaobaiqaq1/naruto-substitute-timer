# v0.2.8 · 头像识别、百战鼬校验与替身计时修复

## 修复内容

- 重做头像识别的有效区域：使用头像脸区掩码和 HUD 锚点，降低段位框、背景和边缘裁切对识别的干扰。
- 扩大但有界的头像候选短名单，并按头像 ID 聚合多尺度匹配结果；加入模板缓存，避免同一头像的不同缩放被错误当成竞争身份。
- 保留头像的规范名称与基础忍者名称，支持“基础忍者标题 + 当前皮肤头像”的证据融合；皮肤头像单独出现时仍只作为展示证据，不会擅自启用皮肤专属豆数、颜色或几何规则。
- 百战鼬（`宇智波鼬[百战]`）继续采用严格双重校验：当前帧完整标题必须与固定右侧头像同时确认；追踪器快速路径也会重新检查头像，避免旧标题或旧模板残留导致误识别。
- 对特殊模板的豆行增加有界的 ±6 像素重定位，只在整行当前采样全部未知时触发，不改变身份判断或放宽单颗豆的颜色门槛。
- 替身观测间隔改为根据实际采集帧间隔自适应，并设置上限，避免识别耗时较长时每帧重置基线、导致替身掉豆无法确认。
