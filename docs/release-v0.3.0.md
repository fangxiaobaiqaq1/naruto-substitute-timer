# v0.3.0 · 手机自动认边、区域校准、更快更省

官网（下载、教程）：https://hy.312166.xyz · BUG 反馈 QQ 群：1109044204

## 新功能

- **手机填名字就能认边**：Android 内置了与电脑版相同的文字识别，填好「我的名字」（游戏账号名）即可自动认出我方；自己的名字被挡住时，看对面的名字反推。不再需要导入账号名图片（仍可选用）。
- **区域校准（豆 / 头像）**：平板、带鱼屏等特殊分辨率识别不准时，可在对局或训练场画面上自己框出两边的豆和头像。界面先画出自动识别实际用的区域，对得上就不用改；只保存改过的框。方案可导出 / 导入，电脑和手机通用。
  - Windows：设置 → 常规 →「区域校准（豆/头像）」
  - 手机：点计时卡片 → 设置 → 位置 →「区域校准」
- **半藏[秽土转生]** 和照美冥[五代目水影] 一样，同时显示 15 秒 / 10 秒。
- **Windows 仅计时器（迷你）重做**：窗口就是计时底板，没有外框；拖右边缘调长度、拖下边缘调高度（数字跟着变大），大小和位置会记住；显示「我方·…」和倒计时；「退出迷你」回到完整浮窗。
- **手机悬浮卡片**：可以直接按住拖动；新增卡片宽度 / 高度（100%–300%）。

## 识别与计时修复

- 九喇嘛水门（金身）的能量条不再把豆读错。
- 采集尺寸略有偏差时也能认出忍者名字（例如六尾鸣人）；更多忍者头像能认出（神秘面具男、佩恩·天道[超]、药师兜[半蛇斗篷]、大筒木浦式[异星钓者] 等）。
- 对手在豆刚恢复的瞬间立刻再次替身，不再漏计。
- 手机：一帧看不清不再清空整局计数；切换采集方式不再凭空多算一次；6 颗豆的忍者在选人前后不再误判；Android 12–13 竖屏开始录屏也能识别。
- Windows：「退出迷你」后不再两个窗口同时出现；配置里的异常数值不再导致一启动就闪退。

## 性能

- 电脑：识别速度约为原来的 5 倍，内存约减半，程序从 81 MB 减到 61 MB。
- 手机：识别核心约快 4 倍、内存更少；对局外每 0.4 秒分析一次（与电脑一致），更省电。安装包变大到约 21 MB，因为内置了文字识别模型。

## 安全与隐私

- 升级到 Go 1.26.10 和新版依赖，修复已知漏洞。
- 导出的诊断包默认用代号替换账号名和电脑用户名，导出窗口会列出包里有什么。
- 手机更新安装前会校验包名、签名和版本号；雷电只从可信的安装目录启动。
