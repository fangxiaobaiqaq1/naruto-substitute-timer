## 新增：开局/换人画面自动认边

- Windows 和 Android 设置中新增 **「开局/换人画面自动认边」**，默认关闭，升级后不会擅自改变原来的认边方式。
- 同时支持三人阵容的开局 VS，以及角色死亡后的单人换人 VS；在进场前读取底部账号名。
- 使用方法：填写并保存 **「我的名字」**（自己的完整游戏账号名），选择 **「自动认边」**，再开启新开关。手机主界面和悬浮窗设置均可操作。
- 此开关独立于战斗画面的名字 OCR；手动选择左边/右边始终优先。只按完整账号精确匹配，不凭称号、等级、加载百分比或陌生文字猜边。
- 换人 VS 不当作新一局重置计时；已有倒计时继续，真正的开局仍由原有对局标记确认。

## 识别修复

- **金身水门（波风水门[九喇嘛连结]）**：更新腾讯官方新版头像，修复训练场能认出、决斗场实战却无法确认身份，进而无法正确定位豆行的问题。电脑版与手机版使用同一份新头像，不降低全局识别门槛。
- **侠隐佐助「烬影绝踪」皮肤**：兼容暗红空豆，并为该皮肤的精确头像应用正确的四槽和下移豆行规则，保留原紫色配色识别。
- **静止加载画面**：异步 OCR 可以在画面不变时完成多次确认，但相同像素仍算重复帧，不会给替身事件额外增加确认票。
- **认边缓存边界**：账号追加后缀、改名或关闭新开关后，不再沿用失效的 VS 认边证据；关闭开关也会清除 VS 来源的侧别缓存，不影响手动侧别及已有替身时钟。

## 升级说明

- Windows 10/11 x64：发布 `timer-app.exe` 和完整工具 ZIP，升级保留原配置。
- Android 12+：发布包含 arm64-v8a / x86_64 的正式签名通用 APK，版本 `0.3.1`，`versionCode 301`；沿用正式发布签名。
- 如果手机装的是测试签名 APK，可能无法直接覆盖安装正式版。这不是下载损坏；请先保存账号、校准等设置，再处理签名迁移，勿直接卸载导致设置丢失。
- 看不清或账号未完整显示时仍会等待可靠证据，可继续使用手动左右。截图与专项回归通过不代表所有画面都能即时识别。
