# v0.3.2 · 秽土柱间、妖怪纲手与黑边适配修复

官网（下载、教程）：https://hy.312166.xyz · BUG 反馈 QQ 群：1109044204

## 识别修复

- **千手柱间[秽土转生]**：补充当前训练场完整标题，修正此前按普通四槽处理的问题。当前完整标题或严格确认的精确头像可以启用六槽红/蓝豆规则；不再漏掉第五、第六颗，也不会把红豆全判成未知。旧决斗标题继续支持。
- **纲手[妖怪奇谭]**：修正红色能量条下方的四颗替身豆采样位置，仅该确切版本的豆行下移 9px（960×540 参考）。不把能量条当替身豆，不将规则套给基础纲手、百豪或其他未核验皮肤。
- **上下黑边**：Android 与新建 Windows 配置默认使用像素证据驱动的 `auto`。只在两侧黑边得到确认时映射实际游戏区域；没有该证据的原生宽屏/平板仍按完整画面处理，不在采集层裁图。
- **训练场工具栏**：扩大正常字号“键位”模板的水平搜索范围，兼容按钮向右移动的位置；匹配阈值保持不变。
- Windows 与 Android 同步上述识别逻辑；保留手工校准、身份失效时的未知保护、原有替身确认和冷却规则。

## 验证与边界

- 用户提供的柱间两图读数为左 5/6、3/6，右侧均 6/6；妖怪纲手图为左药师兜 4/4、右纲手 4/4，并能从该完整截图确认训练场。
- 新增可独立运行的截图回归，覆盖显式缩放、重复采样、合成空豆、身份消失反例、严格头像分差与校准框保存往返。Go/C++ 的完整图像输出一致，相关 `-race`、静态检查及构建检查通过。
- 静态截图、合成序列与主机回归不等于所有设备、特效和完整实战已验收；本次不宣称完成真机安装/整场对战验证。看不清时仍保持未知。

## 升级说明

- Windows 10/11 x64：`timer-app.exe` 和完整工具 ZIP；Android 12+：包含 arm64-v8a / x86_64 的正式签名通用 APK，版本 **0.3.2 / versionCode 302**，沿用正式发布签名。
- **已有 Windows 配置不会被静默改写。** 如果画面确有黑边而 `config.json` 的 `layout.contentMode` 仍为 `"stretch"`，请退出程序后改为 `"auto"`，或重新检查/保存校准。没有黑边或明确需要 stretch 的用户可以继续保留原设置。
- 如果此前为妖怪纲手手工补偿了豆行位置，请先检查新的自动采样点，再重新保存校准，避免重复补偿。
- 训练场标题没有账号文字时，忍者识别成功不代表能自动认出“我方”；仍可在设置中手动选择我方左/右。
- 测试签名 APK 可能无法覆盖正式版；请先备份账号、校准等设置，再处理签名迁移，不要贸然卸载丢失配置。
