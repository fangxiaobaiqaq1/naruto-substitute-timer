# v0.3.3 · Windows 独立性能报告与离线导出

官网（下载、教程）：https://hy.312166.xyz · BUG 反馈 QQ 群：1109044204

## Windows 性能报告

- **独立「性能报告」按钮**：主窗口直接进入，设置页与原诊断窗口也有入口；迷你模式可从设置进入。与「采集与延迟诊断 / 原帧录制」独立，不必开启全量诊断。
- **CPU / GPU / RAM / 显存与系统架构**：查看系统、主进程及已观测进程树的资源占用，区分工作集、Windows 私有提交、Go 堆、专用显存与共享 GPU 内存；记录 CPU 型号/逻辑核数、GPU 型号/驱动、系统版本及系统原生/进程架构。
- **进程树、GC、I/O 与时间线**：提供线程/句柄、协程、Go 堆分配与 GC 次数/频率/暂停、进程 I/O、页错误，以及采集/分析耗时、交付帧龄和 UI 排队信息。可「标记卡顿」，离线报告提供时间曲线、峰值、均值、P50/P95/P99、趋势与采样缺口。
- **离线 ZIP / HTML / CSV / JSON**：支持「停止并导出 ZIP」或监测中导出当前一致快照。ZIP 包含 `report.html`、`report.md`、`metadata.json`、`summary.json`、`samples.csv` 与 `samples.jsonl`；解压即可离线查看，无需网络或服务，图表压缩不删除原始采样。
- **可选脱敏 profile**：可附加开始/结束的 Go 堆 `.pprof` 与协程栈快照。绝对文件路径简化为文件名，保留函数/行号；原始 profile 经内存管道脱敏，不先落盘。快照不是完整内存转储，不含 ORT 原生堆，也不强制 GC。

## 验证与边界

- **监测默认关闭，不随重启自动恢复，不录制游戏画面、不自动上传。** 开启后默认每秒采样一次；未开启前没有历史记录。关闭性能窗口仍继续监测，主窗口按钮显示「进行中」；退出程序会停止并保留原始数据。
- **GPU 不可用会明确显示原因，不以 0 冒充测量结果。** GPU 指标依赖 Windows WDDM/PDH、驱动与权限；部分聚合会标注不完整。GPU 占用按最忙引擎显示，不直接累加不同引擎百分比。
- **增长不等于泄漏，不自动判定内存泄漏。** 应结合持续观测、同场景对照、GC/缓存预热及原生内存数据判断。进程树仅含本程序及已观测后代，不包含独立模拟器或预先运行的 ADB 服务；进程 I/O 也不等于纯物理磁盘吞吐。
- **既有主程序识别算法、采样节奏、替身确认与冷却规则未改。** 每秒一次仅指性能监测；采样/分析次数率不是游戏 FPS，UI 排队时间不是 GPU 呈现或显示器延迟。监测、快照与导出本身仍有额外开销。
- 现有回归与验证入口覆盖采集器、报告导出、隐私/脱敏、并发及前端开关/退出生命周期，并提供本机采集导出自检，详见 [性能报告说明](https://github.com/fangxiaobaiqaq1/naruto-substitute-timer/blob/v0.3.3/docs/performance-report.md#验证入口)；不据此宣称全仓测试通过。**Windows 真机验收尚未进行**，真实驱动、权限及原生界面仍待验证，主机测试或交叉编译不能代替运行验收。

## 升级说明

- Windows 10/11 x64：选择 **v0.3.3** 的 `timer-app.exe` 或完整工具 ZIP，先退出旧程序，再启动新版并核对版本。
- **本次性能报告是 Windows 桌面功能；Android 本次未新增同等性能监测与导出功能。** 不将桌面端能力或验证结论套用到 Android。
- 排查卡顿时点击「性能报告 → 开始性能监测」，复现后标记卡顿，再停止并导出 ZIP；排查纯资源占用时优先只开性能监测，识别误判或截图问题仍使用原诊断入口。
- 数据保存在配置的 debug 目录下的 `performance/perf-时间-随机标识/`；最多 21600 个样本或 64 MiB 时间线，先到即停止并记录原因。历史报告不自动删除，快照与导出另占空间；完整操作及指标口径见 [电脑端性能报告](https://github.com/fangxiaobaiqaq1/naruto-substitute-timer/blob/v0.3.3/docs/performance-report.md)。
