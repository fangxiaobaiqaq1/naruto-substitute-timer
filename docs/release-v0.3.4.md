# v0.3.4 · 性能监测重做：并入设置页，能看出是谁在占用电脑

官网（下载、教程）：https://hy.312166.xyz · BUG 反馈 QQ 群：1109044204

## 性能监测

- **入口改到「设置 → 性能」**：不再有独立窗口和主浮窗上的按钮。监测中时主浮窗的「设置」按钮显示「设置 · 监测中」，关闭设置窗口不会停止监测。
- **能看出是谁在占用电脑**：每秒记录全系统占用最高的程序（同名进程合并），并单独标出模拟器（MuMu、雷电、BlueStacks、夜神、逍遥、腾讯手游助手，按进程名识别）。v0.3.3 只记录计时器自己的进程，说不出整机忙是谁造成的。
- **一次卡顿不再被平均掉**：每秒保留截图、识别、整轮循环的最长耗时，采集失败和超时也计入。
- **GPU 数据更稳**：GPU 单独采样，驱动响应慢时只标「已 N 秒未更新」，不再整场禁用；个别异常计数器行会被跳过，不再让整机 GPU 读数作废。新增整机显存占用。
- **报告先给结论**：`report.html` 开头是几句话的结论和关键数字，然后是进程榜、手动卡顿标记和时间曲线（横轴为时分秒，可对照钟表时间）。`report.md` 改成可以直接贴到聊天里的短摘要。
- **退出也能拿到报告**：监测中直接退出程序会先写好 ZIP；程序被强制关闭或崩溃后，可在「设置 → 性能」点「生成上次记录的报告」。
- **附带更多排查信息**：报告包含错误原文、实际采集方式、记录时的完整设置（`config.json`），以及开始时和每次「标记卡顿」后的一段 CPU 采样。数据只保存在本机 debug 目录，不上传，不录制游戏画面；调试数据可在开始前取消勾选。

用法与读数说明见 [电脑端性能报告](https://github.com/fangxiaobaiqaq1/naruto-substitute-timer/blob/v0.3.4/docs/performance-report.md)。

## 验证与边界

- **Windows 真机验收尚未进行。** 全系统进程枚举与 GPU 计数器读取是 Windows 专属代码，开发环境只做了交叉编译和静态检查；发布流程会在 Windows 上运行采集器测试。如果进程榜为空或 GPU 一直没有读数，请把报告 ZIP 发到反馈群。
- GPU 数据需要 Windows 10 1709 以上和 WDDM 2.x 驱动；没测到的数据显示为「—」，不是 0。
- 识别算法、采样节奏、替身确认与冷却规则未改。

## 升级说明

- Windows 10/11 x64：选择 **v0.3.4** 的 `timer-app.exe` 或完整工具 ZIP，先退出旧程序，再启动新版并核对版本。
- 排查卡顿：「设置 → 性能 → 开始监测」，卡顿时点「标记卡顿」，结束后点「停止并生成报告」，把 `performance-report.zip` 发给开发者。
- **本次改动只涉及 Windows 桌面端；Android 没有功能变化。**
- v0.3.3 留下的性能记录目录可以用「生成上次记录的报告」重新生成；历史记录不会自动删除。
