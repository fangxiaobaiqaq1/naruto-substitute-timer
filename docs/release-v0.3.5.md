## 倒计时提醒（可选，默认关闭）

电脑版在「设置 → 常规 → 倒计时提醒」，安卓在「高级设置 → 倒计时提醒」：

- **提醒秒数**：可填 0.1–15.0 秒，最多一位小数，默认 3.0。倒计时进入这个秒数后变色（原来固定是最后 3 秒变琥珀色）。
- **变红**：开启后，进入提醒秒数时显示红色，不再是琥珀色。完整浮窗、迷你浮窗和两边计时都一样。
- **提示音**：开启后，每次倒计时进入提醒秒数时响一次。内置一段短“叮咚”，也可以导入自己的音效（电脑：WAV / MP3；安卓：WAV / MP3 / OGG / M4A；5 MB 以内）。导入后会复制一份保存，原文件删掉也不影响。有「试听」和「恢复默认音效」按钮；导入的文件坏了或找不到时，会改放内置提示音。

## 升级说明

- Windows 10/11 x64：下载 **v0.3.5** 的 `timer-app.exe` 或完整工具 ZIP，先退出旧程序，再启动新版并核对版本。旧配置文件直接可用，新开关保持默认（公告开、变红和提示音关、提醒 3.0 秒）。
- Android：安装 `naruto-timer-universal.apk` 覆盖升级即可。
