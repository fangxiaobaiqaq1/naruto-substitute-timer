# 使用说明

## 首次使用

先运行 MuMu 和火影忍者，再打开计时器。Setup 为当前用户安装；便携 EXE 放在可写目录。

浮窗显示对面的冷却。首次在「设置 → 常规」选择我方左右位置；训练场没有账号认边证据时，手动选择即可。填写自己的游戏账号名可使用自动认边，不要填写忍者名代替账号。

## 模拟器与多开

「设置 → 模拟器」默认自动检测：仅有一个实例运行游戏时连接它；多个实例同时运行游戏时提示选择，避免任意猜测。

打开模拟器选项卡会自动刷新窗口/进程列表，显示窗口名、PID和多开实例编号；点击一行即可切换。列表第一项为自动检测。一般不需要选择目录；未发现窗口时再展开高级设置指定目录和编号。保存的是稳定的多开编号，重启模拟器后PID变化也不影响选择。切换实例会清除计时并重新建立观测基线。

旧配置中非零实例编号仍按手动选择兼容。特殊旧版 MuMu 若没有实例枚举接口，可手工填写安装目录及编号；无法支持的截图接口会在诊断中说明。

## 常规设置

- 我方位置：左边、右边或自动。手动选择立即生效。
- 我的名字：用于自动认边，支持逗号分隔多个账号名。
- 指定对面忍者：留空自动；只有明确选择的完整版本会启用其特殊显示。
- 默认替身冷却为15秒；照美冥[五代目水影]同时显示15秒/10秒候选，不重复增加次数。
- 内置 OCR 在后台识别，不向网络上传截图。

未知、遮挡、重复或乱序帧不参与新事件确认；已确认的倒计时继续按真实时间运行。

## 关于与更新

浮窗「关于」进入版本页面。检查更新从官方项目 GitHub 获取最新正式版；下拉版本列表可查看日志和发布日期。网络失败时保留已缓存的历史记录，不冒充刚检查成功。

点击下载后可查看进度或取消。校验通过后点击「重启并更新」；建议离开对局后操作。升级仅替换 EXE，保留配置和日志；旁边的 `.previous` 是上一个可恢复版本。新安装器覆盖安装同样保留用户数据。

安装版设置位于 `%APPDATA%\NarutoTimer`；便携版位于程序目录。不要将便携 EXE 放入系统只读目录。卸载后如需删除个人数据，请自行确认该用户目录中的内容。


## 外观与自动更新

在「设置 → 常规 → 外观与更新」中可以调整计时浮窗：

- **窗口不透明度**：40%–100%，只影响计时浮窗，鼠标点击与置顶行为保持不变。
- **计时浮窗字号**：80%–160%，主读秒、双读秒、次数和状态文字一并缩放；窗口会自动留出所需空间。
- 两项均在拖动时立即预览，松开滑块后写入 `config.json`；「恢复默认外观」恢复到 100% 不透明度和 100% 字号。
- **自动检查软件更新**默认开启：正式发布版启动约 10 秒后检查一次，之后最多每 6 小时检查一次。检查只显示新版入口，不会自动下载、安装、重启或抢占对局。关闭后仍可在「关于与更新」手动检查。

发现新版后，浮窗会显示「发现新版本」按钮。进入「关于与更新」后选择“下载更新”，下载完成且通过 GitHub SHA256、大小和版本校验后，仍须由你点击“重启并更新”。
