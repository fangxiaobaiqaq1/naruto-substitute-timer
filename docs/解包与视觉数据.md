## 加密：为什么图抠不出来

热更 / APK bundle 魔数 **`UnityKH1FS`**（`UnityFS` 改 3 字节），Unity `2021.3.16f1`，flags `0x243`。**不是** UnityCN（`0x400`）。

- 改回 `UnityFS` → blocksInfo LZ4 失败
- 单字节 XOR：0 hits
- `bundle.xml` 头 `KHSG`，熵 ~8，跳过
- 决斗场 `dd /proc/PID/mem`：明文资源名 + C# 字符串池里的 `UnityKH1FS`，**0 个可喂 UnityPy 的文件、0 张 PNG**
- **不要 Frida attach** 游戏进程：腾讯 ACE，卡死过一次模拟器

图集在 GPU / 加载回调里，不在可 `dd` 的匿名堆。再解坐标是空转。
