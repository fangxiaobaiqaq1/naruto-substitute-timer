# iOS 专门适配与验收

基线 v0.3.0 / iOS 构建 2；最低 iOS/iPadOS 16.4。主要目标是最新 iOS 27 系列，而不是锁在老系统。iPhone/iPad 横竖屏均开放，使用安全区、独立 Modal 安全区、键盘避让、动态字号和至少 44pt 的操作区域。

## 可自动验证

```bash
cd expo
npm run typecheck
npm test
bash native/recognition/tests/run.sh
npx --no-install expo prebuild --platform ios --no-install
node ios-compat/validate-project.cjs
```

- `check.cjs`：前台计时 hook，休眠/恢复/过期/清理，不重播漏掉的 tick。
- `bridge-check.cjs`：缺少原生模块不能伪成功，设置/状态边界校验，旧轮询不覆盖新事件，后台停止 JS 刷新，手动左右切换、拒绝旧账号字段、特殊忍者和版本比较。
- `controls-check.cjs`：实际 `TimerScreen` 的慢设置读取、原生控制迁移、后台操作回前台、旧 revision、重复通知、明确用户命令与调用失败；避免旧设置覆盖游戏内选择。
- `calibration-check.cjs`：方案格式/大小/越界/导入事务、绘制/移动/缩放/像素调整；40 万组 double/float32 尺寸判定与 Go/C++/Kotlin 摘要相同。
- `modules/naruto-capture/checks/check.cjs`：插件重复执行不重复目标/嵌入、编译设置、资源原始哈希和 pbxproj 往返；macOS 运行原生控制/持久化/有限时间范围/协议测试并对真实 iPhoneOS SDK 执行 Swift 类型检查。
- `native/recognition/tests/`：真实共享 C++ 核心可编译；计时事件、重复帧、恢复即再次替身、断帧、槽数/几何、场景/换轮、手动换边/特殊忍者规则回归。
- `validate-project.cjs`：生成的真实 App 必须依赖并嵌入广播 extension，含真正的识别代码/资源，不能只有占位 plist。
- `validate-app.py`：Xcode 真机产物的 arm64、平台、JS bundle、广播声明、主/扩展版本、原始识别 PNG 字节。
- `select-xcode.py`：选择 runner 已安装的最新正式 Xcode，排除 Beta/RC，打印实际 SDK，不伪报 iOS 27 SDK 已安装。

## 原生生命周期约束

- 采集权限只由 `RPSystemBroadcastPickerView` 获取；启动流程是准备 → 实际开启画中画 → 系统广播 → 游戏。
- Native PiP 渲染与 loopback 结果接收不依赖 React Native 后台 JS。后台没有 PiP 时主动停采集；录屏连接无回应时扩展结束。
- Loopback 限 IPv4 本机，消息大小有界，双方有会话/序号及心跳检查。设备截图不通过该通道传输。
- 倒计时使用确认事件的采集时间；PiP 把截止时间映射到单调时钟，系统时间调整不重新开始。断连/模糊帧只撤销证据，不撤销确认过的计时。
- PiP 的系统后退/前进回调映射到我方左/右，中间播放/暂停回调映射到单/双边；不改变时钟速率，不暂停计时或录屏。系统关闭、媒体会话中断仍按真正停止处理。复杂设置不伪装成视频内容中的可点按钮。
- iOS 没有 Android 无障碍截图备用路径；没有录屏授权/签名扩展就没有自动采集。

## 必须真机测试（尚未由 Linux 或 CI 代替）

以下全部是**发布验收项，不是已通过记录**。只有真实设备测试后才能填通过：

1. **自签完整包**：免费/付费账号工具分别重签 app、appex、framework；允许工具改 Bundle ID 后仍能选中广播。断网冷启动不依赖 Metro，权限/签名过期给出可解释失败。
2. **最新 iOS 27.x + iOS 26 / 18 回归**：iPhone 小屏/刘海/灵动岛、iPad 4:3，横竖屏与大字体、设置 sheet/Files picker/分享弹层/键盘不遮挡关键控件。
3. **画中画真实后台**：PiP 开启后切入游戏连续 15 分钟，native 样本帧数持续增加；关闭/贴边/缩放、进入控制中心、锁屏、来电、耳机/音频会话中断；系统暂停时不能声称继续采集。
4. **图像方向/坐标**：横屏左/右、竖屏启动再转横屏、NV12/BGRA；左右头像、HUD 豆位置与截图一致，不能上下翻转。iPad/宽屏分辨率校准和重新取帧。
5. **实战识别**：普通/特殊豆色、木叶创立柱间 6 豆、九喇嘛水门/侠隐佐助/百战鼬的下移豆行、VS/选人/结算/训练；卡顿/断帧/遮挡不凭旧帧多算。
6. **计时状态机**：两帧确认的单豆下降、1→0、多豆下降不算、恢复瞬间立即再用、轮次清倒计时但整局计数保留、连续结算帧才离场；15/10 秒以同一事件为起点。
7. **游戏内控制**：轻点 PiP 后左右系统键都可用，左/右能立即选我方位置，中间键切单/双边；连续点同方向不来回翻转。测试中间键显示“播放”时，后台连续15分钟仍有新帧/新替身事件，不因播放器暂停样式冻结；下方显示的我方位置要与实际输出一致。回 App 不跳回旧侧别、冷启动恢复记住的位置、不记住时只在新进程恢复默认左边；换边不重置倒计时/次数/轮次、覆盖只影响对面。没有账号/自动认边入口。
8. **校准编辑**：Files 的 PNG/JPEG/方向、四框绘制/移动/缩放、未改区域仍自动；电脑/安卓方案互导；错误版本/超大/越界拒绝；比例差提醒，取消/下滑关闭不保存。
9. **诊断/更新**：分享 JSON 无账号/截图，断网/超时不死等，不误下载 APK/EXE，不自动安装/重启；自动检查可关闭。
10. **隐私/功耗**：录屏音频不存储、不上传游戏帧；PiP 关闭/停止后 socket、帧处理、定时器和音频会话释放。后台 15 分钟功耗/温升可接受。

## 尚无等价实现的非核心功能

Windows 原帧/滚动录像、模拟器诊断、桌面快捷键不在 iOS 包中；当前游戏帧的自动校准几何预览也不能靠截图编辑器冒充。自动认边、账号 OCR/图片模板已按用户要求移除，不列为待补功能。请对照 `expo/README.md` 的对应关系，不宣称“所有平台所有功能均已通过真机验收”。
